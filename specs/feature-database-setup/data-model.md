# Data Model: PostgreSQL schema

Equivalent to SQLite schema version 4. Names, constraints and meanings are unchanged; only the
column types differ. This is the baseline `_migrate_v1` of the PostgreSQL migration chain.

## Tables

### schema_version
| Column | Type | Notes |
|---|---|---|
| version | integer, NOT NULL | Single row. Replaces `PRAGMA user_version`. Updated in the same transaction as each migration. |

### users
| Column | Type | Notes |
|---|---|---|
| id | bigint, identity (GENERATED BY DEFAULT) | Primary key. Migrated ids are copied; sequence is reset afterwards. |
| username | text, NOT NULL | Unique case-insensitively via unique index on `lower(username)`. |
| password_hash | text, NOT NULL | Copied verbatim. Never logged. |

### expenses
| Column | Type | Notes |
|---|---|---|
| id | bigint, identity | Primary key. |
| user_id | bigint, NOT NULL | References `users(id)` ON DELETE CASCADE. |
| description | text, NOT NULL | CHECK `length(trim(description)) > 0`. |
| amount_cents | bigint, NOT NULL | CHECK `> 0`. Integer cents only. |
| category | text, NULL | NULL for legacy rows. CHECK in the frozen category list `_PG_V1_CATEGORIES`. |
| date | text, NOT NULL | ISO `YYYY-MM-DD`. |

Index: `idx_expenses_user_date` on `(user_id, date)`.

### monthly_limits
| Column | Type | Notes |
|---|---|---|
| user_id | bigint | Primary key, references `users(id)` ON DELETE CASCADE. At most one per user. |
| limit_cents | bigint, NOT NULL | CHECK `> 0`. |

### profiles
| Column | Type | Notes |
|---|---|---|
| user_id | bigint | Primary key, references `users(id)` ON DELETE CASCADE. |
| full_name, email, phone, address | text, NOT NULL DEFAULT '' | |
| photo | bytea, NULL | Up to 2 MB, copied byte-for-byte. |
| photo_type | text, NULL | MIME type. |

## Relationships

`users` 1 — N `expenses`; `users` 1 — 0..1 `monthly_limits`; `users` 1 — 0..1 `profiles`.
Deleting a user cascades to all three.

## Migration mapping (SQLite → PostgreSQL)

| Source | Target | Rule |
|---|---|---|
| `users` rows | `users` | Same ids, usernames, hashes. |
| `expenses` rows | `expenses` | Same ids; NULL category preserved; cents copied as integers. |
| `monthly_limits` rows | `monthly_limits` | Same values. |
| `profiles` rows | `profiles` | Photo BLOB → `bytea` unchanged. |
| `PRAGMA user_version` (must be 4) | `schema_version.version` = 1 | Target schema version is its own chain. |

After the copy, each identity sequence is set to the highest copied id so new rows do not collide.

## Verification checks (used by `verify`)

1. Row count per table equal.
2. Per-user sum of `amount_cents` equal.
3. SHA-256 of `photo` equal per profile.
4. `password_hash` equal per user.
